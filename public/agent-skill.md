# Curated Feeds agent skill

Curated Feeds is a free, privacy-first RSS reader for Android, built in Flutter
by Rajat Kashyap. This skill describes how to install it and where its published
resources live.

## What it is

A distraction-free RSS reader for Android. Sources are shown as cards; swiping
right saves an article for later, swiping left marks it done. There are no
ads, no tracking, and no account.

- Version: 1.2.0
- Package: com.curatedfeeds.app
- Requires: Android 8.0 (Oreo) or later
- Price: free, no ads, no in-app purchases
- Privacy: feed list, saved articles, and reading history stay on the device.
  Only anonymous Firebase Analytics counters are recorded.

## How to install

1. Download the APK directly:
   https://apk-download.raj15400881.workers.dev/curated-feeds-v1.2.0.apk
2. Or get it from Uptodown:
   https://curated-feeds.en.uptodown.com/android
3. Open the file and install it.

## How to use it

1. Paste any RSS 2.0, Atom, or RDF feed URL (usually ending in /feed or /rss)
   into the add-source field.
2. Swipe a card right to save an article, left to mark it done.
3. Group sources into categories such as Tech, Design, or News.
4. Articles cache on first read, so they stay available offline.

## Comparables

Account-free and offline-first, unlike Feedly and Inoreader. Android-first
with a swipe-gesture UX, unlike NetNewsWire, which is iOS and Mac only.
